This article is a demonstration of the content workflow and is a draft. It describes the steps to add a new entry without touching any component.

## Create the entry

A single command creates the file in Spanish and English with the schema filled in and the word `TODO` wherever content is missing:

```bash
pnpm content:new blog my-article mi-articulo
```

## Fill in and validate

The `TODO`s are replaced in both languages. Then `pnpm i18n:check` verifies that no key is missing and no value is left empty, and the build validates the schemas.

## Publish

Remove `draft: true` and make the change on a branch. Nothing reaches production without review.
