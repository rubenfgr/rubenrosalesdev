## Problema

El negocio necesitaba medir satisfacción de forma sistemática para detectar incidencias y tomar decisiones basadas en feedback real.

- Encuestas lanzadas de forma poco consistente.
- Dificultad para ver tendencias y puntos de fricción.
- Escasa conexión entre feedback recibido y acciones de mejora.

## Solución

Se desarrolló un sistema NPS que automatiza el envío, centraliza respuestas y convierte feedback en métricas accionables.

- Encuestas post-estancia enviadas automáticamente.
- Dashboards con evolución del NPS y señales clave.
- Priorización de incidencias y oportunidades de mejora.

## Arquitectura

La aplicación se diseñó como producto interno ligero, rápido de iterar y sencillo de mantener.

- TanStack Start y React para una experiencia web moderna.
- PostgreSQL para persistencia y trazabilidad histórica.
- Servicios de backend para orquestar encuestas y explotación de datos.

## Resultado

El equipo dispone de una lectura continua de satisfacción y puede actuar antes sobre los puntos que deterioran la experiencia.

- Seguimiento de NPS en tiempo real.
- Mejor detección de incidencias recurrentes.
- Feedback más útil para mejorar operación y servicio.
