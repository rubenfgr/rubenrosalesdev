## Problema

La gestión de becas requería coordinar solicitudes, documentación y estados dentro de un proceso administrativo con alta carga operativa.

- Múltiples pasos y verificaciones en el ciclo de solicitud.
- Necesidad de trazabilidad para cada expediente.
- Dependencia de coordinación manual entre tareas administrativas.

## Solución

Se implementó un sistema capaz de centralizar solicitudes, validaciones y seguimiento para ordenar la operación y reducir fricción.

- Gestión integral del flujo de becas.
- Seguimiento claro del estado de cada expediente.
- Mejor soporte para la operativa administrativa universitaria.

## Arquitectura

La solución se ajusta al contexto universitario y a sus restricciones tecnológicas sin sacrificar mantenibilidad.

- Angular para la experiencia de usuario y paneles de gestión.
- NestJS para lógica de negocio y procesos administrativos.
- PostgreSQL como base de datos alineada con la infraestructura existente.

## Resultado

La universidad obtiene un proceso más ordenado, trazable y fácil de gestionar en el día a día.

- Menos fricción en la gestión administrativa.
- Mejor seguimiento de solicitudes y documentación.
- Mayor claridad operativa para el equipo responsable.
